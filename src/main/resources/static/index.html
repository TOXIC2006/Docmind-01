to evidence.

A closer look at the decisions behind your answer.

Scoped before search
01 / RETRIEVAL

Meaning meets precision.

Pinecone semantic search recognizes similar ideas. BM25 uses a separate text index to find exact terms, names and identifiers. Reciprocal rank fusion brings both result lists together without mixing incompatible scores.

02 / QUERY REWRITING

A clearer question.

An optional AI pass clarifies wording and corrects typos. We search both your original question and its rewrite, so the original intent stays part of retrieval.

03 / POST-RETRIEVAL

Less noise. More signal.

A deterministic relevance reranker combines semantic similarity, BM25 and term coverage. Extractive compression and duplicate removal keep evidence within character and estimated token budgets. Completion limits cap answer generation.

04 / ISOLATION

Your space stays yours.

Document ownership comes from your authenticated account, never a user ID in a request. Listing, deletion and both search branches enforce the same ownership boundary.

05 / GUARDRAILS

Evidence, not guesswork.

Known instruction-injection and credential patterns are filtered. Answers must cite supplied source IDs or abstain. These checks reduce risk; they do not prove that every generated claim is true.

06 / EVALUATION

Measure before you trust.

Regression tests cover ranking, compression, isolation and guardrails. The live evaluation runner measures Recall@K, Precision@K, MRR, nDCG, citation validity and reference-answer token F1.

mvn test

See RAG_UPGRADES.md and evals/run_eval.py in the project for reproducible evaluation. No quality score is claimed without a run.
